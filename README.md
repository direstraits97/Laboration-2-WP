# Laboration 2 - Webbutveckling för WordPress
## Om uppgiften
Dessa filer ligger till grund för en webbplats jag gjort i syfte att lära mig objektorienterad PHP med databasanslutning. Under mappen diagram finns ett ER-diagram för tabellen informationen lagras i, och även ett UML-diagram som beskriver properties och metoder i en klass. Webbplatsen gör det möjligt för användaren att lägga till och ta bort innehåll i en Bucketlist, där man kan ange namn, beskrivning och prioritetsnivå.
